# CHANGELOG

## 未发布：0.7.0-cloud-feishu-relay（2026-08-07）

- 新增手机到云端的提醒快照上报协议；云主机不读取 WebDAV，仅负责保存提醒、到点发送飞书和失败重试。
- 设置页新增“云端飞书提醒（手机离线也可推送）”开关，默认打开；开关打开后由云端独占发送飞书，手机仍保留本地提醒，关闭后恢复手机直推。
- 云端按稳定任务 ID 幂等更新和取消，避免重复同步造成重复飞书消息。
- 修复云端工作线程缺少到点门槛导致未来提醒在同步后立即推送的问题；现在仅在 `remind_at` 到达后发送。
